    指標・判定の意味

    「何を表すか」「このアプリでどう見るか」「注意点」の順で確認できます。
    確定テクニカルと14:00暫定テクニカル
    確定テクニカルは前営業日までの確定終値で計算します。暫定テクニカルは14:00頃の現在値を当日の仮終値として再計算します。
    前兆検出には暫定値が有効ですが、市場終了まで変化します。最終的な日足評価は確定値を優先します。
    データ品質・判断ゲート
    取引時間、価格時刻、コアデータの欠損、NIFTY公式クロスチェックを確認します。
    休場・時間外・取引中の古い価格では、第1弾購入ルールを自動確定せず「保留」にします。
    NIFTY50騰落銘柄数
    NIFTY50構成銘柄のうち、何銘柄が上昇しているかを見る市場内部指標です。
    指数上昇でも上昇銘柄が少ない場合は、一部大型株だけの上昇の可能性があります。60%以上を「広範な上昇」の目安にします。
    FII/FPI・DII
    外国機関投資家と国内機関投資家の日次売買動向です。NSEの公表値を取得します。
    14:00時点では当日分がまだ確定していないため、通常は前営業日以前の公表値です。補助情報として使い、単独で判断しません。
    前兆スコアの過去検証
    NIFTY日足だけで再現できるテクニカル中核スコアについて、過去に閾値以上になった後の5日・20営業日の実績を集計します。
    現在の総合スコアには為替・原油・VIX・騰落銘柄数・FII等も含むため、検証値をそのまま総合スコアの的中率とは解釈しません。
    NIFTY 50
    インドの主要50社で構成される代表的な株価指数です。このアプリの中心となる市場価格です。
    現在値だけでなく、前日終値、5・25・75日線との位置、前回14:00値との比較を合わせて見ます。
    5日・25日・75日移動平均
    一定期間の終値平均です。5日線は約1週間、25日線は約1か月、75日線は約3か月の方向感を見る目安です。
    価格が線の上か下かに加え、乖離率を見ます。線を超えただけで売買を決めません。
    RSI(14)
    直近14期間の上昇・下落の強さから、過熱・売られ過ぎを測る指標です。一般に30付近以下は低位、70付近以上は高位とされます。
    30以下だから即買い、70以上だから即売りではありません。低位から上向くか、高位から下向くかという変化を重視します。
    MACD / Signal / Histogram
    短期・長期EMA（指数移動平均）の差からトレンド変化を見る指標です。HistogramはMACDとSignalの差です。
    Histogramがマイナスでも、前日より改善していれば下落モメンタムが弱まっている可能性があります。
    USD/INR
    1米ドルが何インドルピーかを示します。数値上昇はルピー安です。
    ルピー安が急速に進む局面は、海外資金や輸入物価の面でインド株の逆風になり得るため、5日変化も確認します。
    Brent
    国際的な原油価格の代表指標です。インドは原油輸入国のため、急上昇は貿易収支や物価の逆風になり得ます。
    価格水準だけでなく、5日間で急騰しているかを前兆スコアに使います。
    India VIX
    インド株市場の予想変動率を表す指標です。一般に上昇は市場の不安定化を示します。
    絶対値だけでなく5日変化を確認します。取得できない場合は前兆スコアから除外します。
    買い場前兆スコア
    RSI低位、RSI改善、MACDヒストグラム改善、5日線回復、外部環境の落ち着きなどの条件一致度を0〜100で表します。
    100%の上昇確率を意味しません。「買い場形成の条件がどの程度そろっているか」の補助指標です。
    売り場前兆スコア
    RSI高位、モメンタム悪化、25日線からの上方乖離、外部環境悪化などの条件一致度を0〜100で表します。
    売却を自動決定する指標ではありません。過熱と内部悪化が同時に起きているかを見る補助指標です。
    1か月見通し
    現在と似た過去局面を、RSI、移動平均位置、MACDヒストグラム、5日騰落率、20日ボラティリティから探し、その後20営業日の実績分布を表示します。
    過去の類似は将来の同一結果を保証しません。平均だけでなく、中央値、25〜75%範囲、最大下落も確認します。
    アノマリー
    曜日、月、月末・月初、連続下落後などに過去繰り返し観測された統計的傾向です。
    因果関係ではなく、将来も続く保証はありません。平均騰落率、上昇率、サンプル数を必ずセットで見ます。
    前回14:00比較
    平日14:00前後に保存した過去スナップショットと、現在値を比較します。
    GitHub Actionsの5回実行のうち、価格時刻が14:00 JSTに最も近い値を1日1件だけ保存します。
    本アプリは市場状態の確認と判断支援を目的としています。前兆スコア、バックテスト、過去統計、類似局面は将来の値動きや利益を保証しません。データ品質・基準時刻・サンプル数を確認し、売買の最終判断は利用者が行います。
