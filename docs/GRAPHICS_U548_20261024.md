## Why three

1. **Necessary:** Charts are already useful, but fixed-size plots are harder to read on iPhone. Existing 60 daily candles obscure longer moves even though verified OHLC is available. A summarized QC/14:00 status without direct evidence can cause incorrect attribution of late GitHub runs to actual captures.
2. **Insufficient today:** Japan UI offers zoom/pinch and quality evidence drilldown, and isolated US preview validates longer OHLC before offering horizontal scroll. India UI has 5 tabs, 30-day NIFTY/RSI/MACD, 60 daily candles, 6-month NAV trend, 28-day reference charts, quality under Management, and confirmed 200 OHLC rows, but no opt-in zoom/200-row selector or direct QC focus.
3. **Minimal safe change:** Public HTML/CSS/JS only. Never modify Private market data, model/threshold, timeline, 14:00 record selection, external provider, regular trade status, purchase cycle, local purchase/review records, dynamic JSON, or existing public allowlist. Avoid displaying unknown MA or volume values as if observed.

## UX delivered in branch

### Zoomable charts
- Buttons beside five chart headers: fund NAV, NIFTY line, RSI, MACD histogram, NIFTY candles.
- Overlay clones **currently displayed SVG only**; no indicator recomputation, API call, or storage.
- Zoom: 100–250%, +/- buttons, pinch, horizontal scrolling, fit, Escape/close/outside tap. Focus is restored to the button that opened the dialog; keyboard tab stays within the dialog. Enlarged chart is labeled as reference data, not a trade signal.
- Current NIFTY support-line evidence and separate confirmed/draft technicals stay unchanged. Retain status colors (positive green, negative red; RSI 50 neutral benchmark) rather than transplant Japan/US red-up/blue-down.

### Candlestick window
- Keep the previous 60-candle initial view. Add 30, 60 and optional 200 trading-day records.
- 200 loads `nifty_ohlc_history.json` **only on user selection**. Validate schema/method-version, real date order, 200–250 saved records, finite positive OHLC bounds, individual close-consistency status, confirmed last day, and every overlapping saved 60-record OHLC before displaying. Reject mixed or older dataset with a visible reason and revert to normal 60. Do not fabricate missing rows or substitute zero for missing volume.
- Long records have no MA values, so the 200-record view explicitly **hides MA** and explains this. No MA recalculation. Keep 200-row X scrolling at latest/right edge. Existing 60/30 retained MA data is unchanged.
- Ignore late network responses when user selected another period or market snapshot changed. Do not auto-fetch 200 on routine PWA load.
