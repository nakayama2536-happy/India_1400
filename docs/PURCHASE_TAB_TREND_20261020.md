# UI v5.40: トレンド拡大と購入状況の独立

## 変更

- 基準価額トレンドの SVG 高さを 400 から 640 に変更。横幅を維持し、高さは v5.39 の 1.6 倍。CSS の縦横比も 17:10 から 17:16 に合わせる。
- 判断タブの順序を「売買判断目安 → 基準価額トレンド → インド・コア最新情報」に変更。
- 「購入状況」タブを新設。管理にあった3分割購入記録・実施日・次の確認対象と、判断にあった3分割実行条件を同じタブへ移動。
- 管理の購入状況の重複を解消し、3分割の説明も購入状況へ移す。予測の説明は予測条件、売り注意の説明は判断理由へ集約する。
- ナビゲーションは「判断・購入状況・指標・予測・管理」の5項目。

## 維持する動作

購入記録の保存キー・日付・確認操作・段階連動・リセット処理、実行条件、売買判定、鮮度条件、JSON データは変更しない。実施状況の変更後は従来どおり、記録と実行条件の表示を同時更新する。

## 確認

- 関連する既存 Node テスト66件、PR静的検査、インラインJavaScript構文、公開配信ゲートが成功。
- HTMLのID一意性、5タブ、グラフ直下の最新情報、購入記録と実行条件の移動先、管理側の重複除去を確認。
- タブ操作の模擬実行で5ページの切替、品質詳細への直接移動・展開・フォーカスを確認。タブ切替による記録書き込みなし。
- 購入記録・実行条件・売買判定の関連関数が変更前と同一であることを確認。
- 保存済み122点のトレンドを比較し、価格目盛り・日付・値動きの形状が維持され、SVGの高さが1.6倍であることを確認。
- グラフを幅330px・高さ311pxで画像化して表示を確認。実機Safariでの確認ではない。
