# UI 5.54｜判断タブの視認性基準を4タブへ展開（2026-10-25）

## 背景・対象
UI 5.53の判断タブはiPhone 17実機画像で良好と評価された。残る「購入状況」「指標」「予測」「管理」の細かな文字を、本文・状態14px、値18px前後、見出し21px、行間約1.7の階層に揃える。

## 変更点
- 専用のcross-tab-readability.cssを追加し、4タブだけにCSSを適用する。
- 購入状況：3つの購入実施記録と市場条件を明確に区別し、実施日・HOLD理由を拡大する。既存の実施日確認とlocalStorage保存操作を維持する。
- 指標：NIFTY・RSI・MACD・外部環境の見出し・基準日・凡例・説明を拡大。SVG描画、軸、支持線、拡大・ピンチ、200本照合は一切変更しない。
- 予測：検証1/3/14営業日のカードを小画面2列＋全幅、359px以下1列にする。結果・未評価・不足履歴を表示したままにし、30件到達だけでは正式採用しない。
- 管理：品質・鮮度・14:00取得証拠、参照時刻、ChatGPT深掘り、取得診断、個人評価を14px前後へ。操作領域は48〜50pxを基本とする。警告や取得失敗を隠さず、展開説明の仕組みも維持する。
- 状態色の意味は変更しない。緑の取得確認と「購入可能」、投信の値動きは別の概念。
- UI_VERSIONを5.54、PWAのキャッシュ名と起動URLを更新。cross-tab-readability.cssをアプリシェルに含める。

## 不変条件とゲート
Private Core、公開データJSON、売買条件、14:00定点取得・保存窓、予測式・評価、品質・鮮度ロジック、個人の購入/評価履歴、APIキー・機密情報には変更を加えない。

静的テスト・既存Node/Python回帰・Security/PR Validation・公開範囲・Pages反映を確認する。GitHub上の成功とiPhone17実機受入は別ゲートとし、画面幅320〜430pxの折返し、safe-area、固定5タブ、グラフ拡大、折りたたみ、購入記録・評価機能を実機で確認する。
