# UI v5.39: 判断後のトレンドと画面整理

## 要望と変更

- 基準価額トレンドを、判断タブの「今日の売買判断目安」のすぐ下へ移動。v5.38 の縦長表示と既存の履歴・価格範囲は維持する。
- RSI(14) の 50 に金色の破線を追加。「50 基準」を左側に表示し、最新の線との重なりを避ける。凡例にも基準線の意味を明記し、RSI 本体の水色と区別する。30・70 の既存補助線も維持する。
- 予測タブの「1・3・14営業日の詳細を見る」と重複予測一覧を削除。現在の予測値は判断タブに集約し、予測タブは過去予測の検証、予測条件・基準、読み方を表示する。
- 品質の独立タブを廃止し、管理タブの「データ品質・取得状況」に集約。品質・鮮度・14:00状態、理由、取得元と時刻、色の説明、前回比較、監査情報は保持する。
- 判断タブの参照データ時刻から、管理内の品質詳細を展開して移動するボタンを追加。下部ナビゲーションは判断・指標・予測・管理の4項目。

## 影響範囲

表示構成と補助線のみの変更。売買判定、閾値、鮮度ゲート、取得スケジュール、購入記録の保存、JSON データには変更を加えない。品質情報の計算・更新は移動前と同じ関数で継続する。

## 確認

- 関連する既存の Node テスト 66 件が成功。
- PR Validation の静的検査、インライン JavaScript 構文、公開配信ゲートが成功。
- HTML 構造を確認：ID 重複なし、トレンドは判断カード直下、品質情報は管理内、予測の重複一覧なし、タブ4項目。
- DOM 操作の模擬実行で、品質ボタンから管理タブへ移動し、詳細の展開・スクロール・見出しへのフォーカスが行われることを確認。購入記録の書き込みはない。
- 予測データの利用可能・利用不可の両方で、移動後の表示が更新されることを確認。
- 保存済み RSI 履歴の描画パスが変更前と同一で、50 の補助線だけが追加されることを確認。SVG を画像化して色分けを確認。実機 Safari の確認ではない。

既存 CI の専用品質タブを前提とする配置検査は、管理内への集約を確認する検査へ更新する。
