# India UI 5.55 — 押せる操作と表示専用情報の識別

基準日：2026-10-25 JST
基準Public main：`9b9a06d0af678c7855803ca61914d100f461b996`（UI 5.54）
状態：承認済みユーザー要望に対する**表示専用PR候補**。CI・公開・iPhone実機は別ゲート。

## 結論

iPhone 17縦画面で、**押すと何かが起こる箇所**を明るい青の枠・塗り・わずかな立体感と矢印/拡大/開閉記号で示す。値や市場状態を伝える**表示専用カードとステータス**は淡い色・フラットな枠で維持し、誤タップを防ぐ。色だけの区別はしない。

既存の「判断」「購入状況」「指標」「予測」「管理」5タブの構造、UI 5.51～5.54の文字階層を変えない。新規ボタンや自動実行の仕組みは追加しない。

## 根拠と必要性（なぜ3）

1. **必要性**：利用者から「ボタンと表示の見分けがつきにくい」と具体的な実機改善要望。情報量の多い判断画面・品質画面では、押す箇所が見分けられないと詳細情報の発見が遅れる。
2. **現状不足**：`.secondary`と`.note`/状態タイル、`summary`と単なるカード、緑/黄/赤の状態表示とタップ可能な品質カードは、暗い背景・細い枠・近い色の組合せ。可視文字は改善済みでも操作の区別は不十分。
3. **最小安全**：新規 `interaction-clarity.css` を既存スタイルの最後に追加し、実際のbutton/summary/selectだけを操作可能な形へ。読み取り専用のtile/pill/next-actionには操作記号を付けない。JSイベント/保存処理、各市場判断式、データQC色・ラベル/正式判定は不変更。

## 破壊的操作と安全境界

- 「購入進捗をリセット」は既存の`記録のリセット`詳細の中に維持する。見た目のボタン化で自動実行したり、確認処理を省略したりしない。
- `button:disabled` は押せるように誤認させず、無効表示・shadowなし・矢印なし。既存の無効条件を変えない。
- キーボード操作時は`:focus-visible`の強い輪郭で操作可能を示し、`:active`では指による押下反応を返す。動作アニメーションが苦手な設定`prefers-reduced-motion`も守る。
- `statusTileHtml`/品質チェック結果、`formal_action`/SHADOW、market phase、14:00定点の保存条件、公式NAV基準日、予測計算・method_versionは変更しない。
- Public JSON、個人の購入/レビュー記録、LocalStorage/IndexedDB、他アプリキャッシュ、CloudflareやSecrets、Private/Coreには触れない。Service Workerは自アプリの版だけ5.55に更新する。
