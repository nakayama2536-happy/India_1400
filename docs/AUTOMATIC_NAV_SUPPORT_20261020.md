# UI v5.41: 基準価額の自動サポート候補

## 目的

インド・コア基準価額トレンドに、履歴から算出した下値の参考線を自動表示する。注文・購入段階・売買判定には連動させない。

## 算出仕様

- 対象は表示中の直近185暦日の基準価額。10観測未満は算出しない。
- 前後2観測のすべてより低い値を谷として確認する。最後の2観測は谷の候補に使わない。
- 谷の間隔は5観測以上。中心から±1%の価格帯に2つ以上ある場合に支持線候補とする。中心値は谷の中央値へ収束させる。
- 価格帯下限を割り込んだ観測より前の谷は回数に含めない。支持線の中心値は最新基準価額以下に限定する。
- 最新値に近い候補から、価格帯の重複しない最大2本を青い破線で表示する。
- 複数回の支持線候補がない場合に限り、その後に割り込んでいない直近の確認済みの谷を、灰色点線の「直近安値目安」とする。「1回の安値・複数回の支持は未確認」を明記する。
- 日付・正の有限価格・日付順序・日付重複に不整合がある場合は候補を出さない。横ばい・単調上昇・単調下降から谷を捏造しない。
- 最新基準価額の基準日・値と履歴末尾が一致しなければ支持線を保留。キャッシュ済み履歴が最新値と一致しない場合は再取得を試みる。

これらの数値は本アプリの表示用の設計値であり、有効性を実証した投資戦略や最適値ではない。線は表示基準日時点で算出したもので、過去の各時点で利用可能だったシグナルではない。分配金による基準価額変化は調整しない。

## 画面

- グラフへ水平線・価格ラベル・根拠となる谷の印を追加。
- グラフ下に基準日、候補価格、下げ止まり回数、該当日、谷を確認できた日を表示。
- 折りたたみに算出方法と表示の意味を記載。
- 元の基準価額の線、価格目盛り、日付、縦長比率は維持。

## 検証

新規12ケースと既存66ケースの合計78テストが成功。支持線割れ後の回数リセット、独立していない谷の除外、直近2観測の未確認、履歴不整合、基準価額との不一致と回復、読込失敗時の表示クリアなどを確認。新規テストを既存PR検証へ追加した。

PR静的検査・インラインJavaScript構文・公開配信ゲートも成功。保存データ122観測では、2026-10-20基準で2026-10-09の14,877円が「直近安値目安」、確認日は2026-10-14となる。複数回の支持を確認した線とは表示しない。

実際のSVGを幅330pxで画像化して確認した。実機Safariの受入確認ではない。購入記録、売買閾値、市場データの生成処理は変更しない。
