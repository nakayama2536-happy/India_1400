## 表示対応

| 色 | 意味 | 例 |
|---|---|---|
| 緑 | 鮮度・基準を確認済み | 鮮度は範囲内、確定日足、基準日確認済み |
| 黄 | 参考値または取得対象外 | 休場日の参考値、休場・取得省略 |
| 赤 | 更新・確認が必要 | 更新が必要＋経過分、取得失敗、今回未取得、利用不可、未来時刻、時刻不明 |

緑は購入許可ではなく、値のプラス/マイナスの方向色とも別。黄色は最新値への昇格や売買適格化を意味しない。
休場による省略の黄表示には当日の生成日時、明示的な休場判定、skipped=true、available=false、エラーなしを要求する。古い休日JSON、未来生成時刻、単なる欠損や取得失敗は免除しない。値は補完しない。
休場日でも為替・原油の経過時間を評価する。NIFTY・VIXは既存の品質条件を満たす休場参考値だけ黄色にする。
表示更新は既存の時計再描画を利用し、市場データを再取得しない。ブラウザが停止中の正確な更新時刻を保証しない。
