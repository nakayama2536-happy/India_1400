インド株 14:00 CHECK（PWA） v1
================================

目的
----
iPhoneで、毎日14:00のインド株チェックを同じ条件で行うためのローカルPWAです。
市場データは手入力です。外部APIやOpenAI APIは使いません。

主な機能
--------
・NIFTY 50、移動平均、RSI、MACD、支持線、出来高等を入力
・0〜100点の「ルール一致度」を算出
・3分割購入のしきい値（初期値 60 / 75 / 90）を表示
・履歴をiPhone内に保存
・履歴をJSONファイルとしてバックアップ
・インストール後はオフライン動作

重要
----
スコアは将来の上昇確率ではありません。
入力したテクニカル条件が、設定した押し目条件にどの程度一致しているかを示す補助指標です。

iPhoneに入れる方法
------------------
PWAとしてホーム画面に追加するには、HTTPSで公開する必要があります。
無料で行う場合は GitHub Pages / Cloudflare Pages / Netlify などが使えます。

GitHub Pagesの概略:
1. GitHubで無料アカウントを作成
2. 新しいRepositoryを作成
3. このZIP内のファイルをすべてアップロード
4. Settings → Pages
5. Deploy from a branch → main / root を選択
6. 表示された https://... のURLをiPhoneのSafariで開く
7. Safariの共有ボタン → 「ホーム画面に追加」

注意:
・iPhoneのブラウザデータを削除すると履歴も消えることがあります。
・定期的に「履歴を書き出す」でバックアップしてください。
・市場データ自動取得は第2版で追加可能です。
